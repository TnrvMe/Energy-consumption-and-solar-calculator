# طاقة العراق

موقع ثابت (vanilla HTML/CSS/JS، بدون خطوة بناء) يضم أداتين للبيت العراقي.
منشور على Vercel: **https://iraqelec.vercel.app**

## الصفحات

| المسار | الصفحة | الملف | صورة المعاينة |
| --- | --- | --- | --- |
| `/` | الواجهة — تعريف واختيار بين الأداتين | `index.html` | `og-home.v2.png` |
| `/bill` | حاسبة فاتورة الكهرباء (الشرائح التصاعدية) | `bill.html` | `og-image.v2.png` |
| `/solar` | حاسبة الطاقة الشمسية | `solar.html` | `og-solar.v2.png` |

المسارات النظيفة تأتي من `cleanUrls` في `vercel.json`. لكل صفحة عنوانها ووصفها وصورة
معاينتها الخاصة، فلا تتشارك الصفحات الثلاث معاينة رابط واحدة.

## تحديث تعرفة الكهرباء ⚡

**كل الأسعار في مكان واحد: [`tariff.js`](tariff.js).**

عند تغيير وزارة الكهرباء للتعرفة، عدّل مصفوفة `TIERS` في أعلى الملف
(و`META.updated` و`META.source`) — لا شيء آخر. الصفحتان تقرآن منه:

- شريط الشرائح وجدول التعرفة والمثال المحسوب في صفحة الفاتورة
- سطر «التسعير المتدرج الرسمي» وجدول الشرائح في صفحة الطاقة الشمسية
- كل حسابات الفاتورة والتوفير في الأداتين

لا توجد نسخة ثانية من الأسعار في أي ملف.

```js
var TIERS = [
  { upTo: 1500,     rate: 10,  ... },
  { upTo: 3000,     rate: 35,  ... },
  { upTo: 4000,     rate: 80,  ... },
  { upTo: Infinity, rate: 120, ... }
];
```

## الهوية البصرية

كل قيم التصميم في `:root` أعلى [`site.css`](site.css)، ونسختها الليلية في `html.dk`.
الصفحات الثلاث لا تكتب لوناً واحداً مباشرة — بل تشير إلى هذه الرموز:

| المجموعة | الرموز |
| --- | --- |
| التمييز | `--brand` `--brand-deep` `--brand-soft` `--brand-line` `--brand-ring` |
| دافئ (رسوم الشمس فقط) | `--amber` `--amber-soft` `--amber-line` |
| الأسطح | `--page` `--panel` `--panel-2` `--panel-3` |
| النصوص | `--ink` `--ink-2` `--ink-3` `--ink-4` |
| دلالية | `--info` `--good` `--warn` `--bad` (+ `-soft` و`-line`) |
| الشرائح | `--t1`…`--t4` — تُحقن من `tariff.js` عند التحميل |
| الحواف | `--r-xs` `--r-sm` `--r` `--r-lg` `--r-xl` `--r-pill` |
| الظلال | `--shadow` `--shadow-2` `--shadow-sm` `--shadow-cta` |
| الخطوط | `--font-display` (Baloo Bhaijaan 2) · `--font-body` (Cairo) |

المكوّنات المشتركة في نفس الملف: `.btn` `.pill` `.site-nav` `.hero` `.stats`
`.steps` `.tool` `.cta-band` `.handoff` `.tool-hero` `.site-foot` و`.blobs`
(طبقة أشكال SVG عضوية زخرفية، `aria-hidden` دائماً).

**عند تغيير الهوية:** عدّل `:root` و`html.dk` في `site.css` فقط — الصفحتان
`bill.html` و`solar.html` تعيدان تسمية هذه الرموز محلياً (`--gold`، `--sun`…)
فتتبعان التغيير تلقائياً. لون `theme-color` مكتوب أيضاً في `<head>` كل صفحة
وفي `site.js`، فحدّثه معها.

## ملاحظات

- **الروابط القديمة:** كانت حاسبة الفاتورة على `/` وروابطها المُشارَكة تحمل
  `?u=<عدد>`. الواجهة تمرّر هذه الروابط فوراً إلى `‎/bill?u=<عدد>‎` عبر سكربت في
  `<head>` يعمل قبل رسم الصفحة، فلا تنكسر الروابط المنشورة سابقاً.
- **الربط بين الأداتين:** بعد حساب الفاتورة تظهر بطاقة تنقل الاستهلاك إلى
  `‎/solar?kwh=<عدد>‎`، وصفحة الشمسي تملأ الحقل وتعرض شارة توضّح مصدر الرقم.
  وفي المقابل تعيدك بطاقة في نتائج الشمسي إلى `‎/bill?u=<عدد>‎`.
- **شريط التنقّل** مكتوب حرفياً في الصفحات الثلاث ليظهر فوراً بلا انتظار
  JavaScript؛ `Site.markCurrentTab()` وحدها تحدّد التبويب النشط من المسار.
- **الوضع الليلي** مشترك بين الصفحات الثلاث، مخزّن في `localStorage` تحت
  `irq_dk`، ويتبع إعداد الجهاز إن لم يختر الزائر شيئاً. يُطبَّق داخل `<head>`
  لتفادي الوميض.
- **حالة صفحة الشمسي** محفوظة كاملةً في `localStorage` تحت `irqSol3`.
- **اللغة:** الموقع عربي بالكامل، `dir="rtl"` في كل صفحة. لا يوجد تبديل لغة.
- **التحليلات:** Vercel Web Analytics عبر
  `‎<script defer src="/_vercel/insights/script.js">‎` في الصفحات الثلاث.
  يتطلّب تفعيل Web Analytics من لوحة تحكّم المشروع على Vercel.
- **صور المعاينة** تُخزَّن `immutable` لسنة كاملة، فاسمها يحمل رقم نسخة.
  عند تحديث الصور: غيّر الرقم في اسم الملف، ثم في وسمَي `og:image` و`twitter:image`
  في الصفحة المعنية، وفي قاعدة `og-…` داخل `vercel.json` — وإلا بقيت النسخة
  القديمة في ذاكرة المتصفحات ومنصّات المشاركة.
- **النطاق:** `iraqelec.vercel.app` مكتوب صراحةً في وسوم canonical و`og:*`
  في الصفحات الثلاث وفي `sitemap.xml` و`robots.txt` — صور المعاينة تتطلّب
  رابطاً مطلقاً. عند الانتقال إلى نطاق خاص استبدله في تلك الملفات ثم أعد فحص
  الروابط في [أداة فيسبوك](https://developers.facebook.com/tools/debug/).

## التشغيل محلياً

```bash
npx http-server . -p 8080
```

لمحاكاة `cleanUrls` افتح `‎/bill.html‎` و`‎/solar.html‎` مباشرةً؛ على Vercel
تعمل `‎/bill‎` و`‎/solar‎`.
