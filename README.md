# طاقة العراق — Energy & Solar Calculators

موقع ثابت (vanilla HTML/CSS/JS، بدون خطوة بناء) يضم أداتين متكاملتين للعراق:

| المسار | الأداة | الملف |
| --- | --- | --- |
| `/` | حاسبة فاتورة الكهرباء — الصنف المنزلي بنظام الشرائح | `index.html` |
| `/solar` | حاسبة الطاقة الشمسية — حجم المنظومة والتوفير | `solar.html` |

الأداتان تتشاركان الهوية البصرية والوضع الليلي وشريط التنقّل، وتحيل كل منهما
إلى الأخرى مع تمرير الاستهلاك: `/` ترسل `‎/solar?kwh=…‎` و`/solar` ترسل `‎/?u=…‎`.

## تحديث تعرفة الكهرباء ⚡

**كل الأسعار في مكان واحد: [`tariff.js`](tariff.js).**

عند تغيير وزارة الكهرباء للتعرفة، عدّل مصفوفة `TIERS` في أعلى الملف
(و`META.updated` و`META.source`) — لا شيء آخر. الصفحتان تقرآن منه:

- شريط الشرائح وجدول التعرفة والمثال المحسوب في صفحة الفاتورة
- سطر «التسعير المتدرج الرسمي» وجدول الشرائح في صفحة الطاقة الشمسية
- كل حسابات الفاتورة والتوفير في الأداتين

لا توجد نسخة ثانية من الأسعار في أي ملف — بحث `grep` عن الأسعار داخل
`index.html` أو `solar.html` يجب ألّا يعطي نتيجة.

```js
var TIERS = [
  { upTo: 1500,     rate: 10,  ... },
  { upTo: 3000,     rate: 35,  ... },
  { upTo: 4000,     rate: 80,  ... },
  { upTo: Infinity, rate: 120, ... }
];
```

```

robots.txt
```

## ملاحظات

- الوضع الليلي مشترك بين الصفحتين، مخزّن في `localStorage` تحت `irq_dk`،
  ويتبع إعداد الجهاز إن لم يختر الزائر شيئاً. يُطبَّق داخل `<head>` لتفادي الوميض.
- صفحة الطاقة الشمسية تحفظ كامل حالتها في `localStorage` تحت `irqSol3`
  (واللغة تحت `irq_lang`).
- الروابط العميقة: `‎/?u=2500‎` تملأ حاسبة الفاتورة، و`‎/solar?kwh=2500‎` تملأ
  حاسبة الشمسية وتفتحها على الخطوة الأولى مع شارة توضّح مصدر الرقم.
- النطاق الحالي: **https://iraqelec.vercel.app** — مكتوب صراحةً في
  `index.html` و`solar.html` (canonical و`og:url` و`og:image` و`twitter:image`)
  وفي `sitemap.xml` و`robots.txt`. صور المعاينة تتطلّب رابطاً مطلقاً، فلا يمكن
  جعلها نسبية.
- عند الانتقال إلى نطاق خاص: استبدل `iraqelec.vercel.app` في تلك الملفات
  الأربعة، ثم أعد فحص الرابطين في
  [أداة فيسبوك](https://developers.facebook.com/tools/debug/) لأن معاينة
  الروابط القديمة تبقى مخزّنة عندهم.

## التشغيل محلياً

```bash
npx http-server . -p 8080     # ثم افتح http://localhost:8080
```

لمحاكاة `cleanUrls` محلياً افتح `‎/solar.html‎` مباشرةً؛ على Vercel يعمل `‎/solar‎`.
